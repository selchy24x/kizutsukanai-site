最終更新日: 2026-07-26

第4条 公開される情報

1.
ユーザーが共有リンク、QR コード又はプロフィール ID を用いて公開したプロフィール情報は、当該リンク又は ID を知る第三者に閲覧される場合があります。
2.
フレンド申請又はフレンド登録に際しては、相手に見せるよう選択したプロフィール情報が、当該相手に表示されます。
3.
ユーザーが設定したアバター画像は、プロフィール表示に伴って相手ユーザーに表示されることがあります。
4.
連絡ルームでは、当該ルームの参加者に対し、ルーム内で表示されるプロフィール情報、メッセージ本文、送信者表示、送信時刻その他連絡機能の利用に必要な情報が表示されます。

第5条 Google カレンダー連携および AI 利用

1.
ユーザーが Google カレンダー連携を有効にした場合、運営者は、連携対象カレンダーの一覧メタデータ、連携状態、認証情報その他必要な情報を取得・保存します。
2.
本サービスは、招待の時間重複判定補助のため、Google Calendar API から空き・埋まり判定に必要な範囲の freebusy 情報のみを利用します。現時点では、Google カレンダー上の予定タイトル、説明、参加者その他のイベント詳細は取得しません。
3.
本サービスは、日時解釈及び重なり判定の補助のため、招待のタイトル、詳細、日時文面並びに前項の範囲の freebusy 情報から抽出した重複判定用データを OpenAI に送信する場合があります。
4.
前項の送信にあたっては、ユーザー ID、公開プロフィール ID、フレンド情報その他判定に不要な識別情報を OpenAI に含めない実装を前提とします。
5.
前各項に基づいて利用する freebusy 情報その他の予定関連情報は、招待ブロック判定に必要な範囲でのみ判定処理中の一時メモリ上で扱い、サーバーに保存しません。
6.
将来、Google カレンダーから取得する情報の範囲が広がる場合であっても、当該追加情報は招待ブロック判定に必要な範囲でのみ一時的に利用し、サーバーに保存しません。
7.
連携解除時には、Google カレンダーに関する秘密情報、カレンダー一覧その他運営者が保持する連携関連情報を削除し、関連するカレンダーブロック設定を無効化します。

第7条 保存期間

1.
運営者は、取得した情報を、利用目的の達成に必要な期間又は法令上必要な期間保存します。
2.
少なくとも、以下の情報は次の方針で取り扱います。
OAuth 状態管理用の一時情報: 通常10分程度で失効し、遅くとも24時間以内に削除
Google カレンダー連携情報: 連携中又は再認証が必要な期間保存
Google カレンダー秘密情報: 連携解除時に削除
Push 通知の配送先として登録された端末情報: 最終利用日から1年間利用がない場合、削除又は無効化の対象となることがあります。なお、通知不能と判定された端末情報は、それ以前に無効化又は削除する場合があります。
アプリ内通知: 作成時から1年間を目安に保存
連絡ルーム及びメッセージ: 連絡機能の提供、履歴表示、不正利用対策及びトラブル対応に必要な期間保存
エラーログ: 記録時から180日間を目安に保存
利用規約、プライバシーポリシー及び年齢確認に関する同意履歴: 同意取得時点の版管理、法令対応及びトラブル対応のため、アカウント利用継続中保存
プロフィール情報、フレンド情報、招待履歴、ブロック設定その他サービスの継続利用に必要な情報: アカウントの利用継続中保存
アカウント削除の進捗確認情報: 削除完了から30日。削除完了時にユーザーとの対応関係を切断します。
アカウント削除の監査記録: 削除完了から90日。削除ジョブID、受付・完了日時、結果及び適用方針の版のみを保持し、ユーザーとの対応関係は保持しません。
3.
前項の保存期間は、法令上の義務、紛争対応、不正利用対策、障害対応その他合理的な必要がある場合には、必要な範囲で延長されることがあります。
4.
アカウント削除時には、プロフィール、認証情報、招待、同意履歴その他アカウントに紐づくデータを削除します。Google カレンダー連携中の場合は、連携トークンの失効も試みます。
5.
削除するユーザーが送信した連絡ルーム内のメッセージは、本文、スタンプ及び添付画像を削除します。他の参加者の会話の時系列を維持するため、送信日時及び内容が削除済みであることを示す表示に必要な最小限のメッセージ行のみを、送信者との対応関係を切断して残します。他の参加者が送信した内容は削除しません。
6.
他のメンバーがいる所有サークルについては、アカウント削除前に所有権を移譲するかサークルを削除する必要があります。所有権を移譲したサークルの名称、説明及び画像は、移譲後の所有者が管理するサークルのデータとして残ります。他のメンバーがいない所有サークルはアカウント削除時に削除します。
7.
バックアップに含まれる削除対象データは、通常のバックアップ更新周期に従って上書きされ、それまでの間は復旧又は保全目的以外に利用しません。

第8条 安全管理

運営者は、取得した情報について、不正アクセス、漏えい、滅失、改ざん等を防止するため、合理的な安全管理措置を講じます。

特に、Google カレンダー連携に関するアクセストークン及びリフレッシュトークンについては、通常の接続テーブルから分離し、制限された権限でのみアクセス可能な構成を採用しています。

また、現時点で講じている主な安全管理措置の概要は次のとおりです。

権限分離及び最小権限化
秘密情報テーブルの分離
認証、通知及び外部連携に関するアクセス制御
障害調査に必要な範囲に限定したエラーログ保存
外部送信先、送信項目及び送信目的の定期確認

第9条 ユーザーの選択、開示等の請求手続及び問い合わせ

1.
ユーザーは、プロフィール情報、フレンド情報、招待情報、連絡機能に関する通知設定、通知設定、Google カレンダー連携設定の一部を、本サービス上で変更できます。
2.
ユーザーは、Google カレンダー連携を解除できます。
3.
ユーザーは、Push 通知をオフにできます。ただし、Push 通知をオフにしても、アプリ内通知一覧に通知が保存される場合があります。
4.
ユーザーは、フレンド削除、サブプロフィール削除等、個別データの削除を行える場合があります。
5.
ユーザーは、設定画面の「アカウント削除」又は公開Web削除ページから、本人確認を行った上でアカウント削除を申請できます。通常の本人確認手段を利用できない場合は、お問い合わせ窓口から削除を申請できます。
6.
ユーザーは、法令の定めに従い、保有個人データに関する開示、訂正、追加、削除、利用停止等を求めることができます。
7.
前項の請求又は相談は、第12条のお問い合わせ窓口に対し、開示等を求める対象、登録中のメールアドレスその他運営者が本人確認に必要と判断する事項を付して行うものとします。
8.
運営者は、請求者が本人又は適法な代理人であることを確認するため、追加情報又は確認資料の提示を求める場合があります。
9.
運営者は、法令上応じられない場合、過大な負担を要する場合又は請求内容が不明確な場合、回答又は対応を留保し、理由を付して案内することがあります。
10.
開示等の請求に関する手数料は、現時点では定めていません。ただし、将来手数料を定める場合は、事前に本ポリシー又は本サービス上で案内します。

第10条 未成年者に関する取扱い

本サービスは、13歳以上の方を対象とします。13歳未満の方は、本サービスを利用できません。

第11条 本ポリシーの変更

1.
運営者は、必要に応じて本ポリシーを変更できます。
2.
誤字修正、連絡先変更又は説明の明確化等、ユーザーの権利利益及び個人情報の取扱いに実質的な影響を与えない変更は、改定版又は改定履歴の公表により周知します。
3.
機能追加その他、ユーザーが内容を把握することが適切な変更は、アプリ内表示、ウェブサイト掲載その他適切な方法で通知します。
4.
個人情報の利用目的を従来の目的と関連性を有すると合理的に認められる範囲を超えて変更する場合、本人の同意を根拠とする第三者提供を新たに行う場合その他法令上同意が必要となる重要な変更については、変更内容を個別に示し、適用前に明示的な同意を取得します。
5.
前項の重要な変更について、アプリの利用を継続したことのみをもって同意したものとは扱いません。同意しないユーザーには、適用開始前にアカウント削除を申請できる手段を案内します。
