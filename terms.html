傷つかない招待アプリ 利用規約

最終更新日: 2026-05-03

本利用規約（以下「本規約」といいます。）は、Selchy（以下「運営者」といいます。）が提供する「傷つかない招待アプリ」およびこれに関連するウェブサイト、アプリケーション、サポート窓口その他一切の関連サービス（以下「本サービス」といいます。）の利用条件を定めるものです。ユーザーは、本規約に同意のうえ、本サービスを利用するものとします。

第1条 本サービスの内容

1.
本サービスは、ユーザー同士がフレンド登録を行い、個別の招待や募集を送受信できるサービスです。
2.
本サービスでは、招待内容を段階的に開示し、相手が任意の段階で見送れる設計、ならびに一定条件のもとで招待を表示しない又は再表示を遅らせる仕組みを採用しています。
3.
本サービスには、公開プロフィール、サブプロフィール、フレンド管理、招待履歴、通知、招待成立後の連絡ルーム、Google カレンダー連携による招待ブロック補助等の機能が含まれます。
4.
本サービスは、招待又は募集が成立したユーザー間で、連絡、日程調整その他成立後のやり取りを行うための連絡機能を提供する場合があります。

第2条 利用資格

1.
本サービスは、運営者が定める条件を満たす者のみが利用できます。
2.
ユーザーは、自己のためにのみ本サービスを利用し、第三者になりすまして利用してはなりません。
3.
本サービスは、13歳以上の方を対象とします。13歳未満の方は、本サービスを利用できません。
4.
過去に本規約違反その他の理由で利用停止等の措置を受けた者は、運営者の判断により利用を拒否されることがあります。

第3条 アカウント登録および認証

1.
ユーザーは、メールアドレス OTP 認証、Google ログイン、LINE ログイン、Yahoo! JAPAN ID ログインその他運営者が認める方法により、本サービスを利用できます。
2.
ユーザーは、登録情報を真実、正確かつ最新の内容に保つものとします。
3.
ユーザーは、自らの端末、認証手段、ログイン状態等を適切に管理し、第三者に不正利用させてはなりません。
4.
運営者は、登録内容が不正確である場合、第三者の権利利益を侵害するおそれがある場合、又は本規約違反のおそれがある場合、アカウントの利用を制限できるものとします。
5.
ユーザーは、退会又はアカウント削除を希望する場合、運営者が指定するお問い合わせフォームを通じて申請するものとします。アプリ上の退会又はアカウント削除機能は現時点では未実装です。

第4条 プロフィール、フレンド登録および公開範囲

1.
ユーザーは、表示名、プロフィール文、プロフィール ID、アバター画像その他運営者が定める情報を設定できます。
2.
ユーザーは、相手ごとに表示させるプロフィールを選択できる場合があります。
3.
ユーザーが共有リンク、QR コード又はプロフィール ID を用いて自身のプロフィールを共有した場合、当該共有先の第三者は、当該プロフィール情報を閲覧できることがあります。
4.
ユーザーは、フレンドに関するグループ分け、ニックネーム、メモ、ブロック設定等を本サービス上で行うことができます。
5.
ブロック機能を利用した場合、当該相手からの招待は表示されない又は制限されることがあります。

第5条 招待、募集およびシステム判定

1.
ユーザーは、フレンドに対して招待又は募集を送信できます。
2.
ユーザーは、招待又は募集の作成にあたり、タイトル、日程に関する文面、詳細、回答期限、希望連絡手段その他運営者が定める情報を入力できます。
3.
本サービスは、ユーザー設定、ブロック設定、Google カレンダー連携の有無、日程判定、その他運営者が定める条件に基づき、招待の表示、非表示、再表示時期、送達先の一部制限等を行う場合があります。
4.
ユーザーは、本サービスの特性上、送信した招待が常に相手に表示されるとは限らず、また、相手の判断又はシステム判断の詳細理由が常に開示されるものではないことをあらかじめ了承するものとします。
5.
運営者は、招待又は募集の表示順、表示方法、通知方法、履歴表示の内容を、必要に応じて変更できるものとします。

第6条 連絡機能

1.
連絡機能は、招待又は募集の成立後に、当該成立に関係するユーザー間の連絡を補助する目的で提供されます。
2.
ユーザーは、連絡機能において送信するメッセージ、プロフィール表示、その他の情報について、自ら責任を負うものとします。
3.
ユーザーは、連絡機能を用いて、嫌がらせ、脅迫、わいせつな表現、差別的表現、営業・勧誘目的の大量送信、個人情報の不当な収集又は公開、その他第三者に不利益又は不快感を与える行為をしてはなりません。
4.
運営者は、法令対応、不正利用対策、障害調査、ユーザーからの通報又は問い合わせ対応、その他本サービスの安全な運営に必要な範囲で、連絡機能に関する情報を確認し、保存し、又は必要な措置を講じることがあります。
5.
運営者は、連絡機能におけるメッセージの到達、通知、既読表示、相手からの返信、日程調整の成立その他ユーザー間のやり取りの結果を保証しません。

第7条 外部サービスとの連携

1.
本サービスは、Google、LINE、Yahoo! JAPAN、Firebase Cloud Messaging、Supabase、OpenAI その他の外部サービスと連携する場合があります。
2.
Google カレンダー連携を利用する場合、ユーザーは Google の認可画面において必要な権限を付与するものとします。
3.
ユーザーが外部サービスのアカウント又は機能を利用する場合、当該外部サービスの利用規約、プライバシーポリシーその他の条件もあわせて適用されることがあります。
4.
外部サービス側の障害、仕様変更、認証失効、権限不足その他運営者の合理的支配を超える事由により、本サービスの一部機能が利用できない場合があります。
5.
利用者情報の外部送信に関する詳細は、プライバシーポリシー及び別途定める 利用者情報の外部送信について によります。

第8条 禁止事項

ユーザーは、本サービスの利用にあたり、以下の行為をしてはなりません。

1.
法令又は公序良俗に違反する行為
2.
犯罪行為、違法な勧誘、迷惑行為、ストーキング、嫌がらせ、脅迫その他第三者に不利益又は不快感を与える行為
3.
虚偽のプロフィール、なりすまし、本人の承諾なく第三者の情報を登録又は利用する行為
4.
不正アクセス、リバースエンジニアリング、スクレイピング、過度な自動送信その他本サービスの運営を妨害する行為
5.
招待、募集、プロフィール、メモ、連絡機能その他の入力欄に、運営者が不適切と判断する内容を投稿又は送信する行為
6.
本サービスを通じて取得した他ユーザーの情報を、本サービスの想定範囲を超えて保存、転載、第三者提供又は営業利用する行為
7.
本サービス又は第三者の知的財産権、肖像権、プライバシー権、名誉その他の権利利益を侵害する行為
8.
本サービスの仕様上意図された曖昧さ、非表示処理又は通知制御を不当に回避しようとする行為
9.
運営者が合理的理由に基づき不適切と判断する行為
