傷つかない招待アプリ 利用者情報の外部送信について

最終更新日: 2026-08-02

本書面は、傷つかない招待アプリにおける利用者情報の外部送信について、主な送信先、送信される情報及び利用目的を案内するものです。

1. 基本方針

本サービスでは、認証、データ保存、通知配信、Google カレンダー連携、AI による日時解釈及び重複判定補助その他の機能を提供するため、外部事業者又は外部サービスに対して利用者情報を送信する場合があります。

外部送信は、次のいずれかに必要な範囲で行います。

本サービスの提供及び維持
セキュリティ確保
障害対応
外部連携機能の実現
通知配信
日時解釈及びカレンダー重複判定補助
不正利用の通報受付および安全対応

本書面における 主な所在又は処理地域 は、運営者が現時点で把握している当該事業者の主な所在国、提供主体又は処理地域の考え方を示すものです。実際の保存先や処理地域は、利用リージョン、委託先、サブプロセッサその他の事情により変わる場合があります。

2. 主な外部送信先

Supabase

主な所在又は処理地域: 運営者が利用している Supabase の主要データベースリージョンは東京です。ただし、Supabase 又はその委託先の提供体制により、関連情報が日本国外で取り扱われる場合があります
位置付け: 本サービスの認証、データ保存、画像保存及びサーバ処理を支える基盤提供事業者又は委託先
主な用途: 認証、データベース、ストレージ、Edge Functions
主に送信される情報: メールアドレス、認証結果、プロフィール、フレンド、招待、通知、設定に関するデータ、アップロードした画像、エラーログ、通報者が明示的に提供したメッセージの復号済みコピー、添付プレビュー、補足、通報対象および通報処理情報
送信の主なタイミング: ログイン時、アプリ利用時、データ更新時、画像アップロード時、エラー報告時

Google

主な所在又は処理地域: 米国その他 Google LLC 又はその関連会社が運用する地域
位置付け: ユーザーが選択する認証及び Google カレンダー連携機能の提供元、ならびにアクセスを運営担当者に限定した通報受付キューの提供元
主な用途: Google ログイン、Google カレンダー連携、Google Calendar API の利用、Google スプレッドシートによる通報受付キュー
主に送信される情報: OAuth 認証に必要な情報、Google カレンダー連携時の認可情報、カレンダーの freebusy 照会に必要な情報、通報の受付番号、区分、優先度、確認期限、通報者・対象者・ルームの識別子、証拠件数およびハッシュ値、運営者が通報メッセージ転送を別途有効化した場合に限る補足および通報者が選択した復号済みメッセージのコピー
送信の主なタイミング: Google ログイン時、Google カレンダー接続時、招待ブロック判定時、アプリ内通報の受付時および送信失敗後の再試行時

通報受付シート上のユーザー識別子、ルーム識別子、補足およびメッセージコピーは、受付から180日で日次処理により消去します。必要最小限の受付番号、区分、件数およびハッシュ値は監査のため残る場合があります。

LINE

主な所在又は処理地域: 日本その他 LINE Yahoo グループが運用する地域
位置付け: ユーザーが選択する認証連携先
主な用途: LINE ログイン
主に送信される情報: OAuth 認証に必要な情報、ログイン結果の照合に必要な情報
送信の主なタイミング: LINE ログイン時

Yahoo! JAPAN

主な所在又は処理地域: 日本その他 LINE Yahoo グループが運用する地域
位置付け: ユーザーが選択する認証連携先
主な用途: Yahoo! JAPAN ID ログイン
主に送信される情報: OAuth 認証に必要な情報、ログイン結果の照合に必要な情報
送信の主なタイミング: Yahoo! JAPAN ID ログイン時

Firebase Cloud Messaging

主な所在又は処理地域: 米国その他 Google LLC 又はその関連会社が運用する地域
位置付け: Push 通知配信を行う基盤提供事業者又は委託先
主な用途: Push 通知配信
主に送信される情報: Push トークン、通知タイトル、通知本文、通知開封導線に必要なデータ
送信の主なタイミング: 通知許可時、端末登録時、通知送信時

OpenAI

主な所在又は処理地域: 米国その他 OpenAI グループ又はその委託先が運用する地域
位置付け: 日時解釈及び重複判定補助を行う外部処理事業者
主な用途: 招待の日時解釈、Google カレンダーとの重複判定補助
主に送信される情報: 招待のタイトル、日時に関する文面、招待の詳細文、重複判定に必要な検索期間、Google freebusy 情報から抽出した重複判定用データ
送信しないことを原則とする情報: ユーザー ID、公開プロフィール ID、フレンド一覧、判定に不要な識別情報
送信の主なタイミング: 招待送信時の日時解釈、カレンダー重複判定時

3. 更新ルール

1.
運営者は、新たな外部送信モジュール、認証手段、通知基盤、AI 処理又は外部連携機能を追加する場合、原則として当該機能の提供開始までに本書面及び関連する法務文書の更新要否を確認します。
2.
既存の送信先であっても、送信項目、利用目的、主な所在又は処理地域その他利用者への説明に影響する重要な変更がある場合、本書面の更新を検討します。
3.
運営者は、外部事業者の仕様変更、サブプロセッサ変更又はリージョン変更により実態とのずれが生じないよう、必要に応じて各事業者の公表資料及び運営設定を見直します。

4. 補足

1.
外部送信先の一部は、日本国外に所在し、又は日本国外のサーバー若しくはインフラを利用する場合があります。
2.
外部送信先、送信項目、送信目的及び主な所在又は処理地域は、本サービスの機能追加、仕様変更、外部事業者の変更その他の事情により更新される場合があります。
3.
法令に基づき、運営者は、外国にある第三者への提供又は外国にある事業者への委託に関して、本人同意、契約、監督その他必要な措置を講じます。
4.
外部送信に関するお問い合わせは、プライバシーポリシー記載のお問い合わせ窓口で受け付けます。
